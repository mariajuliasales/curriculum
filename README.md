# Currículo — Maria Julia Sales

Currículo pessoal em formato de página web feito apenas com **HTML e CSS**, sem frameworks nem JavaScript.

A proposta é fugir do modelo tradicional de currículo em texto corrido. O layout tem uma barra lateral com contatos e competências, e uma área principal com apresentação, experiência e projeto.

## Estrutura

```
curriculum/
├── index.html   # conteúdo do currículo
├── style.css    # estilos e responsividade
└── README.md
```

## Como visualizar

Basta abrir o arquivo `index.html` no navegador. Não há dependências para instalar.

> As fontes **Poppins** e **Inter** são carregadas do Google Fonts, então é preciso estar conectado à internet para vê-las.
